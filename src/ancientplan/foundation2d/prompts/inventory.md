任务：为古画的地面布局建立“所有可见地面相关元素清单”。这是第一阶段，还不是地基标注，也不是俯视图。

只以随附图片为依据。图片中可能存在题跋、印章、装裱边缘；它们不是地面相关元素。
分类限定为：house（房屋）、tree（树）、mountain（山/岩石）、water（水）、flat（平地）、other（其他地面相关元素）。
其他可包括棚架、桥、道路、围墙、船、人等，并用 subtype 区分。不要把开放棚架计为封闭房屋。

规则：
1. 从上到下、从左到右巡查全部画面。不要只选择容易识别的两三栋建筑。
2. 房屋按可区分实例逐个列出；只有一个角或一段屋顶可见的也列候选，标记 partial。
3. 当前阶段的框覆盖“可见外形”，可以包括屋顶和树冠；这些框绝对不能直接作为地基。
4. 被遮挡的轮廓本阶段不补；完全没有图像证据的房屋不要凭空新增。
5. 可分开的树分别列出；无法分开的树丛仍用 category="tree"，subtype="tree_group"，grouped=true，不声称已逐树识别。tree_group 不是合法主类别。
6. 山、水、平地按连续可辨区域列出；上方看见山峰，不说明该处对应地基就是山地。
7. 每个条目写出简短可核对的视觉证据，不输出内部思考过程。
8. 遮挡关系只有在有明确依据时才填 occluded_by；仅凭画面上下位置不能确定遮挡顺序。
9. 哪些区域太小、太密或看不清，写入 review_regions，不能用“其他”掩盖不确定性。
10. 自查重复：同一屋顶的多个坡面不是多栋房屋。不要为了凑数拆分或合并。

坐标：全部使用相对于本次输入图片的 0–1000 坐标，左上为 [0,0]，右下为 [1000,1000]。
bbox 格式 [xmin,ymin,xmax,ymax]，边界必须在 0–1000 内。若输入是裁剪图，只输出裁剪图坐标。

仅输出 JSON：
{
  "stage": "visible_inventory",
  "coordinate_system": "image_normalized_0_1000",
  "objects": [
    {
      "id": "H001",
      "category": "house",
      "subtype": "普通房屋",
      "bbox": [0,0,1,1],
      "visibility": "partial",
      "confidence": "medium",
      "grouped": false,
      "evidence": "可核对的可见特征",
      "occluded_by": [],
      "needs_detail_review": true
    }
  ],
  "review_regions": [{"bbox": [0,0,1,1], "reason": "需要局部放大的原因"}],
  "scan_summary": "说明哪些部分已经巡查，哪里仍可能漏检；不可宣称一次全图扫描绝无遗漏"
}
尽量完整，但不要用未知范围中的臆造对象填满清单。
为避免输出被截断：每个对象写成一行紧凑 JSON，evidence 不超过 20 个汉字；不要重复解释规则。
只需定位框，不要在本阶段添加大量多边形点、完整轮廓或补全假设。
